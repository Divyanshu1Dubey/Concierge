WordPress

Add to your theme's footer.php or use a custom HTML widget.

<?php
// Add to footer.php before </body>
$tenant_slug = 'YOUR_TENANT_SLUG';
?>
<script src="<script src="{{API_URL}}/widget.js"></script>
<script>
  HeyJarvis.init({
    tenant: '{{tenant_slug}}',
    apiUrl: '{{API_URL}}'
  });
</script>

Webflow

Project Settings → Custom Code → paste in Footer Code.

<!-- HeyJarvis Concierge -->
<script src="{{API_URL}}/widget.js"></script>
<script>
  HeyJarvis.init({
    tenant: '{{tenant_slug}}',
    apiUrl: '{{API_URL}}'
  });
</script>

Wix

Site Dashboard → Settings → Custom Code → Add code before </body>.

<script src="{{API_URL}}/widget.js"></script>

  HeyJarvis.init({
    tenant: '{{tenant_slug}}',
    apiUrl: '{{API_URL}}'
  });

Plain HTML

Add this before the closing </body> tag.

<script src="{{API_URL}}/widget.js"></script>
<script>
  HeyJarvis.init({
    tenant: '{{tenant_slug}}',
    apiUrl: '{{API_URL}}'

</script>

iFrame Embed

Embed the full concierge page as an iframe.

<iframe
  src="{{APP_URL}}/concierge/{{tenant_slug}}"
  width="400"
  height="600"
  frameborder="0"
  style="border:none;position:fixed;bottom:0;right:0;z-index:9999;"
  title="Concierge Chat">
</iframe>

Google Tag Manager

Add a Custom HTML tag in GTM, set to fire on All Pages.

<script>
  (function() {
    var s = document.createElement('script');
    s.src = '{{API_URL}}/widget.js';
    s.async = true;
    document.head.appendChild(s);
    s.onload = function() {
      HeyJarvis.init({
        tenant: '{{tenant_slug}}',
        apiUrl: '{{API_URL}}'
      });
    };
  })();
</script>
