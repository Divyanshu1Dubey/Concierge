AI-powered dental concierge chat widget for WordPress. Embed intelligent appointment scheduling on your dental practice website.

== Description ==

HeyJarvis AI Chat brings intelligent dental concierge functionality directly to your WordPress website. The plugin embeds a beautiful, customizable chat widget that helps your patients:

* Schedule appointments 24/7
* Get instant answers to common questions
* Browse available time slots in real-time
* Receive personalized care recommendations

= Features =

* Easy embed via shortcode, widget, or Gutenberg block
* Customizable colors, titles, and welcome messages
* Practice-specific configuration
* Mobile-responsive design
* GDPR-compliant

= Requirements =

* WordPress 5.0 or higher
* PHP 7.4 or higher
* A HeyJarvis account with a valid Practice ID

= Configuration =

1. Go to **Settings → HeyJarvis** in your WordPress admin.
2. Enter your Practice ID provided by HeyJarvis.
3. Customize the widget appearance (colors, title, welcome message).
4. Save settings.
5. Add the widget via the HeyJarvis Chat widget, the `[heyjarvis_chat]` shortcode, or the HeyJarvis Chat Gutenberg block.

== Installation ==

1. Upload the `heyjarvis-chat` folder to `/wp-content/plugins/` on your server.
2. Activate the plugin through the **Plugins** screen in WordPress.
3. Go to **Settings → HeyJarvis** and configure your Practice ID.
4. Add the chat widget to your site using a widget, shortcode, or Gutenberg block.

== Frequently Asked Questions ==

= How do I get a Practice ID? =

Contact HeyJarvis support or sign up at [heyjarvis.com](https://heyjarvis.com) to receive your unique Practice ID.

= Can I customize the widget colors? =

Yes. Go to **Settings → HeyJarvis** and use the color picker to set your primary brand color.

= Is the chat widget mobile-friendly? =

Absolutely. The widget is fully responsive and works seamlessly on all device sizes.

= Where can I find the Practice ID? =

Your Practice ID is provided when you sign up for HeyJarvis. You can find it in your HeyJarvis dashboard under Settings.

= Does this plugin slow down my website? =

No. The HeyJarvis widget loads asynchronously and is optimized for performance with minimal impact on page load times.

= Is the plugin GDPR compliant? =

Yes. HeyJarvis is designed with privacy in mind. Please consult your legal team for specific compliance requirements.

== Privacy Policy ==

HeyJarvis AI Chat connects to the HeyJarvis API to provide chat functionality. Chat messages are transmitted to HeyJarvis servers for processing. No personal data is stored locally by this plugin. Please refer to the HeyJarvis privacy policy at [heyjarvis.com/privacy](https://heyjarvis.com/privacy) for details on how your data is handled.
